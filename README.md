# VisionMind AI

An AI business co-pilot for smart retail using computer vision, machine learning and generative AI.

## Status
Phase 1: frontend dashboard with **synthetic demo data** (no real measurements yet).

## Run the frontend
```bash
cd frontend
npm install
npm run dev
```

## Roadmap
1. Repo and React frontend (current)
2. Full dashboard UI
3. Sales and inventory pages
4. FastAPI backend and database
5. Connect frontend to backend
6. Computer vision on uploaded videos
7. ML forecasting and anomaly detection
8. Generative AI co-pilot
9. Testing, documentation, deployment

> All figures shown in the UI are clearly labelled synthetic demo data until real data is connected.
